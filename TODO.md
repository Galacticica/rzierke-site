# Songwriting Software
## Description
A software tool that allows for the writing of songs, including lyrics and chord pro format. It will allow a user to play chords individually, as well as play their song in its entirety (user sets time and tempo, player reads chords from chordpro format) The software will also allow for the user to save their songs in a database, and retrieve them later for editing or playback.

## Features
- Write lyrics and chords in chord pro format
- Play individual chords
- Play entire song with user-defined tempo and time signature
- Save songs to a database
- Retrieve and edit saved songs
- Export chord charts and lyrics to various formats (PDF, TXT, etc.)
- User-friendly interface for easy navigation and song creation
